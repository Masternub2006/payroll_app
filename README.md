# Учёт зарплаты в Flutter

Мобильное приложение для ведения списка сотрудников, ежемесячных начислений и расчёта ФОТ.

## Имеется
- Сотрудники: добавление, изменение и удаление.
- Тип оплаты: фиксированный оклад или почасовая ставка.
- Ежемесячные записи: часы (для почасовой оплаты), премии, отпускные, комментарий и ставка/оклад за конкретный месяц.
- Автоматический расчёт выплаты и общего ФОТ при изменении данных.
- Переключение месяцев и просмотр истории начислений.
- Локальное сохранение данных на устройстве.

## Запуск (требуется установленный Flutter SDK.)
Обычный:
```bash
flutter run
```
Веб-версия:
```bash
flutter run -d web-server
```
Тесты расчётов:
```bash
flutter test
```

## Правило расчёта
- Фиксированная оплата: оклад за месяц + премии + отпускные.
- Почасовая оплата: отработанные часы × ставка за час + премии + отпускные.
- Если запись за выбранный месяц отсутствует, начисление равно 0 (при добавлении сотрудника с фиксированным окладом - создается запись за этот месяц).
- Ставка/оклад, введённые в месячной записи, имеют приоритет для этого месяца и не меняют базовую ставку сотрудника (изменение базовой ставки происходит в редактировании данных сотрудника).
